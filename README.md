# 月次帳票 自動生成ツール

仕訳データ（CSV）から、月次決算で使用する帳票一式をExcelブックとして自動生成するツールです。

## 開発の背景

経理部門で子会社4社の月次決算を担当していた際、決算を締めたあとに
**月次推移表・前年度比較表・部門別売上表を毎月手作業で作成**していました。
4社分を並行して作成するため相応の工数がかかり、また転記の過程で
ミスが起こりうる作業でもありました。

さらに、作成した資料をもとに前月比較を行い、**増減の大きい勘定科目について
仕訳内容や備考欄まで遡って変動要因を特定し、上席へ報告する**運用を毎月継続していました。
この「どの科目が動いたか」「なぜ動いたか」を突き止める工程が、
毎月もっとも時間を要する部分でした。

本ツールは、この一連の作業を仕訳データから自動化することを目的として作成したものです。

## 生成される帳票

| シート | 内容 |
|---|---|
| 試算表 | 対象月の勘定科目別 借方・貸方・当月残高・累計残高 |
| 月次推移表 | 損益科目 × 12ヶ月の推移と年度累計 |
| 前年度比較表 | 当年度累計と前年度累計の対比（増減額・増減率） |
| 部門別売上表 | 部門 × 月の売上と年度累計（合計行付き） |
| 差異分析 | **前月比でしきい値以上増減した科目を抽出し、当月の主要な仕訳を摘要付きで併記** |

差異分析シートが本ツールの中心です。
増減額の大きい順に科目を並べたうえで、その科目の当月仕訳のうち金額上位3件を
「部門名：摘要 金額」の形式で表示するため、**数字が動いた理由をシート上で追跡できます。**

## 入力データの検証

集計の前に、以下を検証して問題があれば処理を中止します。
経理帳票は数字が合っていることが前提であるため、
「誤った数字を出力しない」ことを優先した設計としています。

1. 必須列の存在確認
2. **仕訳全体の貸借一致**
3. **伝票単位での貸借一致**（一致しない伝票番号を提示）
4. 勘定科目マスタ・部門マスタに存在しないコードの検出

## 使い方

```bash
pip install -r requirements.txt

# 動作確認用のダミー仕訳データを生成（2会計年度・約4,300明細）
python generate_dummy_data.py

# 対象月を指定して帳票を生成
python main.py --month 2026-01
```

出力先: `output/月次帳票_YYYYMM.xlsx`

実際に生成されたExcelの例を `sample/` に置いています。

## 入力ファイルの形式

### data/journal.csv（仕訳データ）

会計ソフトからエクスポートした仕訳日記帳を想定した、1行＝1明細の形式です。

| 列 | 内容 |
|---|---|
| 日付 | 伝票日付（YYYY-MM-DD） |
| 伝票番号 | 貸借一致の検証単位 |
| 部門コード | 部門マスタと突合 |
| 勘定科目コード | 勘定科目マスタと突合 |
| 借方金額 / 貸方金額 | 金額（整数） |
| 摘要 | 差異分析の変動要因欄に表示 |
| 税区分 | 課税区分 |

### data/accounts.csv（勘定科目マスタ）

`勘定科目コード, 勘定科目名, 区分(BS/PL), 大分類, 貸借区分, 表示順`

**貸借区分**により、資産・費用科目は「借方−貸方」、負債・純資産・収益科目は
「貸方−借方」で残高を計算します。

### data/departments.csv（部門マスタ）

`部門コード, 部門名, 表示順`

## 設定（config.yaml）

```yaml
company_name: サンプル株式会社
fiscal_year: 2025           # 会計年度
fiscal_start_month: 4       # 期首月
variance_threshold: 100000  # 差異分析の抽出しきい値（円）
```

集計条件をコード内に埋め込まず設定ファイルに外出ししているため、
決算期の異なる会社にもファイルの変更のみで対応できます。

## ダミーデータについて

`generate_dummy_data.py` は動作確認用の仕訳データを生成します。
実在の企業のデータは一切含みません。

季節変動を反映した売上、売上に比例する費用、固定費に加え、
**減価償却費の月次計上・前払費用の振替・水道光熱費の見越計上といった
決算整理仕訳**を含めています。
また、差異分析の動作を確認できるよう、特定月に意図的な異常値
（設備の緊急修繕、キャンペーン広告、寒波による電気代増加）を仕込んでいます。

生成時に借方合計と貸方合計の一致を検証します。

## 構成

```
monthly-report-generator/
├── main.py                  エントリポイント
├── generate_dummy_data.py   ダミー仕訳データ生成
├── config.yaml              設定
├── data/                    マスタ・仕訳データ
├── output/                  生成されたExcelブック
└── src/
    ├── loader.py            読み込みと検証
    ├── reports.py           集計ロジック
    └── excel_writer.py      Excel出力・書式設定
```

読み込み・集計・出力を分離しているため、
入力形式が変わっても `loader.py` の修正のみで対応できます。
